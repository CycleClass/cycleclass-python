# Curso de Python do Zero · CycleClass

Código das **missões** (exercícios) do curso gratuito de Python do CycleClass, apresentado pela Matsue no YouTube.

▶️ Canal: https://youtube.com/@cycleclass26

## Como usar

- Cada aula tem uma pasta (`aula-03`, `aula-04`, …) com a resolução das 3 missões dela.
- Tente resolver sozinho primeiro! A partir da Aula 05, a resolução vem no final da própria aula, e o código aparece aqui no mesmo dia.
- Para rodar: abra o arquivo `.py` no [Thonny](https://thonny.org) e aperte **F5**. A instalação está na Aula 02.

## O curso

36 aulas em 3 níveis, 102 missões e 3 projetos:

| Nível | Aulas | Temas | Projeto |
|---|---|---|---|
| 1 · Iniciante | 1 a 12 | print, variáveis, input, operadores, strings, if, while, for | Jogo de adivinhar |
| 2 · Intermediário | 13 a 24 | listas, tuplas, dicionários, funções, módulos, erros, arquivos | Gerador de escala |
| 3 · Orientação a Objetos | 25 a 36 | classes, herança, polimorfismo, composição, JSON, testes | Sistema de escalas |
